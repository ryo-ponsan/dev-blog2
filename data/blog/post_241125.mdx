# 本書を読んだモチベーション
発表資料やwebデザインなど、感覚的に、キーワードを目立たせる、空間を適切に空ける、といったことで意識をなんとなくしてきたが、言語化することができなかったため、デザインに関する制作を勉強する上で、自身のデザインの軸の言語化をすべき、初学者向けの本書を選定。

```
一度名前を言えるようになった途端、それを意識し、コントロールし、所有できるようになる
```

# 言語化


## 1.近接
- 組織化
- 関連する要素を近づけてグループ化
- 情報が組織化されれば読んでもらえる可能性も高くなる
- 副産物として、より魅力的な空白を生み出すこともできる

### 気にすること
- ページを見て目に留まった回数が3~5回超えれば（例A4のチラシ）、１個の視覚的ユニットにできないか検討。感覚的な部分もある

### 避けること
- ページ上に個別の要素作りすぎないこと
- 見出し、小見出し、キャプション、画像が、本文のどの部分に関連するかを読者が一瞬でも迷わないように。要素間の関連を近接によって作り出す
- 異なる要素間に関連を作らない。関連しないものは離す


## 2.整列
- 名刺で、右揃えにすると、テキストを結びつける透明な線が見え力強く見える。
- チラシについて中央揃えでも、全体配置を右側に寄せるなど工夫するとかっこいい
- 筆者のおすすめは中央揃えをしばらく使わないようにすること。ただ明確に意図的な場合クール
- 意味なく配置してはいけない。全ての要素が視覚的なつながりをもつようにする。paddingだったり、配置を意識できるようにする


### 避けること
- 同じページで2種類以上の文字ぞろえを用いないこと

## 3.反復
- ページを最後まで見たとき、そのページの中に視線が留まる効果も見込める（最初と最後で、デザイン性の反復）
- 一体化と視覚的なおもしろさを加えることができる。おもしろさがあると読んでもらえる可能性が高くなる

### 避けること
- うるさく感じるほど反復させない
